# Blind_Nav_Assistant (视障导航助手)

这是一个基于分布式架构的视障人士辅助导航系统，结合了边缘端视觉感知与中枢端大模型交互。

## 项目架构

### 1. MaixCam 视觉节点 (`cam_node/`)
- **功能**: 实时 YOLO 11 障碍物检测、单目测距、空间定位。
- **协议**: 作为 TCP Server (192.168.233.1:12345)，上报警报并接收查询指令。
- **部署**: 将 `cam_node/` 文件夹上传至 MaixCam 运行 `main.py`。

### 2. 树莓派中枢节点 (`pi_node/`)
- **功能**:
  - **语音交互**: 采用 ASR 监听与 TTS (espeak) 播报。
  - **意图识别**: 内置 **MiniMind (26M)** 轻量级大模型（Intent Brain），精准识别用户意图。
  - **中枢调度**: 连接 MaixCam 视觉流，并根据语音意图下发控制指令。
- **部署**: 在树莓派运行 `main.py`。

## 核心流程
1. **安全模式**: MaixCam 持续扫描，发现 P1 级危险（如汽车）立即通过 Socket 推送给树莓派，树莓派语音报警。
2. **交互模式**: 用户问“苹果在哪里？”，树莓派 MiniMind 识别“寻找”意图，提取“苹果”，下发指令至 MaixCam，MaixCam 开始高亮苹果并语音引导方位。

## 硬件连接
- MaixCam 与树莓派通过 **USB Type-C** 连接。
- MaixCam 需开启 **USB Device (Ethernet)** 模式。
