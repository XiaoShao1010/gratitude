# Gratitude: 基于 MaixCam 的障碍物检测与交互

针对视障人士开发的移动障碍物检测与空间定位应用。

## 功能
1. **模式 A: 障碍物检测**: 实时识别行人、车辆及路障，并根据优先级预警。
2. **模式 B: 空间交互**: 根据用户查询（如“XX在哪里”），实时反馈目标的方位（左、中、右）及估算距离。

## 安装与部署
由于 MaixCam 运行 MaixPy v3，建议直接将 `gratitude` 文件夹和 `main.py` 上传至设备的 `/root/` 或 `/maix/` 路径下。

## 运行
```bash
python3 main.py
```
