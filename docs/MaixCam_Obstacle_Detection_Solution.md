# 基于 MaixCam 的视障人士移动障碍物检测与导航方案

## 1. 项目概述
本项目旨在利用 MaixCam (K230) 边缘计算能力，为视障人士提供实时的障碍物检测、距离感应及语音导航功能。

## 2. 硬件架构
- **处理器**: MaixCam (K230)。
- **传感器**: 500万像素摄像头。
- **反馈**: 3.5mm 音频 + GPIO 振动马达。

## 3. 软件方案
### 3.1 目标检测模型
- **模型**: YOLO11-n (Nano)。
- **目标**: 行人、车辆、自行车、消火栓、树木等。

### 3.2 距离估算
- **算法**: 单目几何投影模型。
- **反馈区**: 危险区 (0.5m-1.5m)、预警区 (1.5m-3.0m)。

### 3.3 交互逻辑与空间定位
- **双模式**: 模式 A (安全预警) + 模式 B (互动寻物)。
- **方位**: 将图像横向分为左、中、右。

## 4. 实施步骤
1. 环境搭建 (MaixPy v3)。
2. 模型准备 (YOLO11 INT8 量化)。
3. 应用开发 (模块化重构)。
